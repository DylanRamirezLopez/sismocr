# Datos

`provincias_cr.geojson`: límites de las 7 provincias de Costa Rica (versión simplificada).

- Fuente: geoBoundaries gbOpen CRI ADM1, derivado de OpenStreetMap (https://www.geoboundaries.org)
- Licencia: Open Data Commons Open Database License 1.0 (ODbL). © colaboradores de OpenStreetMap.
- Solo se cambiaron las propiedades: `shapeName` pasó a `provincia`.
